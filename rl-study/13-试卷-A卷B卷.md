# A 卷 · 原理（90 分钟，100 分）

## 一、填空（每空 2 分，共 20 分）

1. 贝尔曼最优方程里使问题变成非线性的算子是 `______`；它满足 `______` 性质，由 `______` 定理保证唯一不动点。

2. GAE 中 `λ = 0` 等价于 `______`，`λ = 1` 等价于 `______`。

3. PPO 的 clip 作用在 `______` 上，而不是作用在动作上；它的两个边界是 `______` 和 `______`。

4. 致命三要素是：`______`、`______`、`______`。

5. 若 shaping 项写成 `F(s,a,s') = ______`，则最优策略不变。

## 二、判断并说明理由（每题 3 分，共 15 分）

1. 策略梯度里减基线 `b(s)` 的目的是把奖励数值变小，从而训练更稳。
2. `Loss/entropy` 出现负值，说明策略已经完全没有探索能力。
3. PPO 的 `clip_param` 越小，训练一定越稳定。
4. LQR 的最优反馈增益 `K` 依赖于初始状态 `x_0`。
5. 观测器极点配置得越快（越靠左），闭环系统一定越好。

## 三、推导（每题 8 分，共 32 分）

**1.** 从 $J(\theta) = \mathbb{E}_{\tau\sim\pi_\theta}[R(\tau)]$ 出发，推导策略梯度定理。要求：

- 写出 `p_θ(τ)` 的分解；
- 说明为什么 `ρ_0(s_0)` 和 `P(s'|s,a)` 的梯度为 0；
- 用因果性去掉未来奖励；
- 说明基线为什么可以减。

**2.** 证明 GAE 在 $\lambda = 1$ 时等于蒙特卡洛优势估计（写出 $\delta$ 求和与望远镜求和的过程）。

**3.** 标量系统 $\dot x = ax + bu$，代价 $J = \int_0^\infty (qx^2 + ru^2)\,dt$（$q>0, r>0$）。从 HJB 方程推导 Riccati 方程，并给出最优控制律。

**4.** 设 $\hat A > 0$、$\epsilon = 0.2$。证明 PPO 的 clip 目标 $L^{\mathrm{CLIP}} = \min\left(r\hat A,\ \mathrm{clip}(r,1-\epsilon,1+\epsilon)\hat A\right)$ 在 $r > 1+\epsilon$ 时对 $r$ 的导数为 0，并说明这对应"限制步长"的哪一侧。

## 四、计算（每题 6 分，共 18 分）

**1.** 两状态 MDP（`A`、`B`），`stay` 得 $+1$ 留在原地，`switch` 得 $+2$ 切到另一状态，$\gamma = 0.9$。求 $V^*(A)$、$V^*(B)$ 与最优策略（要检验另一分支）。

**2.** 3 步轨迹：$r = [1, 0, 2]$，$V = [5, 4, 3]$（$V(s_0)=5$），$s_2$ 之后终止（$V(s_3)=0$），$\gamma = 0.9$，$\lambda = 0.95$。求 $A_0$ 在 $\lambda = 0$、$\lambda = 1$、$\lambda = 0.95$ 三个值。

**3.** 平面 2R 臂，$l_1 = l_2 = 1$，$q_1 = 30^\circ$，$q_2 = 60^\circ$。求雅可比 $J$ 与 $\det(J)$，并用 $l_1l_2\sin q_2$ 核对。

## 五、简答（每题 5 分，共 15 分）

1. 有人把 `rew_scale_alive` 从 1 改到 5，说"奖励信号强了 5 倍，应该学得更快"。用 advantage 的定义与归一化解释：为什么这个推理不成立？

2. 为什么机器人 RL 普遍用"关节位置目标 + PD 内环"而不是直接输出力矩？给三条理由（分别从稳定性、动作空间、sim2real 角度）。

3. 写出分离原理的内容，并说明它在什么条件下成立、为什么非线性系统一般不成立。

# B 卷 · 综合（120 分钟，100 分）

## 一、系统设计（20 分）

把 cartpole 从"保持竖直"改成 **tracking 任务**：每回合随机目标 `x* ∈ [-2, 2]`，要求 5 s 内把小车开到 `|x - x*| < 0.1` 且杆子不倒下。

请给出：

1. 观测向量（写出每一维、单位、量纲）；
2. 奖励函数（写出每一项的公式、量纲、典型每步量级，并说明为什么）；
3. 终止条件（哪些算 terminated，哪些算 truncated，为什么）；
4. 一个评估协议（初始状态网格、每格 env 数、指标、成功判据）；
5. 至少指出一个"会打架"的奖励项，并写出你的解决办法（提示：势函数）。
