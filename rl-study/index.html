调用顺序（一次策略步）：

step(actions)
 ├─ _pre_physics_step(actions)          # 存动作
 ├─ for i in range(decimation=2):       # 物理 2 步
 │    ├─ _apply_action()                # 力矩写给执行器
 │    └─ sim.step()                     # 物理推进 dt=1/120
 ├─ _get_observations()                 # 新观测
 ├─ _get_rewards()                      # 奖励
 └─ _get_dones()                        # 终止判断（含 reset）

所以：策略 60 Hz（$1/(2\times\frac{1}{120})$），物理 120 Hz。

    pole_pos = self.joint_pos[:, self._pole_dof_idx[0]]
    pole_vel = self.joint_vel[:, self._pole_dof_idx[0]]
    cart_pos = self.joint_pos[:, self._cart_dof_idx[0]]
    cart_vel = self.joint_vel[:, self._cart_dof_idx[0]]

    rew_alive = self.cfg.rew_scale_alive * (1.0 - self.reset_terminated.float())
    rew_term = self.cfg.rew_scale_terminated * self.reset_terminated.float()
    rew_pole = self.cfg.rew_scale_pole_pos * pole_pos.square()
    rew_cv = self.cfg.rew_scale_cart_vel * cart_vel.abs()
    rew_pv = self.cfg.rew_scale_pole_vel * pole_vel.abs()

T2.1 动作空间改造：力矩 → 位置 + PD（关键任务）

目的：这是"玩具"和"真机能用"的分界线。宇树、智元、任何做真机的，底层都是位置/速度目标 + PD，不是裸力矩。

前置：T1.6、T1.10。

原理先说清（30 秒版）：

$$ \tau = K_p\left(q^{\text{des}} - q\right) - K_d\dot q $$

  1. 稳定：PD 提供阻尼，高频振荡被底层吃掉；

T2.4 势函数 shaping 与课程学习

目的：解决"到目标"和"保住杆"打架的问题；学会课程学习。

前置：T2.3。

现象：直接加 $-x^2$ 或 $-|x-x^*|$，策略会为了靠近目标而牺牲平衡，杆子更容易倒。

原理：直接加惩罚会改变最优策略；加势函数之差不会：

$$ F(s,a,s') = \gamma\Phi(s') - \Phi(s),\qquad \Phi(s) = -\tfrac12 k\,(x - x^*)^2 $$

代入得

$$ F = \tfrac12 k\left[(x-x^*)^2 - \gamma (x'-x^*)^2\right] $$

（$x'$ 是下一时刻位置）。望远镜求和后，每条轨迹只差常数 $-\Phi(s_0)$，最优策略不变。

操作：把 T2.3 改 5 的 rew_target 换成 $F$，系数 $k$ 从 0.5 试起。

"""把 Isaac Lab 导出的策略放进 MuJoCo 跑闭环。"""
import numpy as np
import mujoco
import torch

MJCF = "mujoco/cartpole.xml"
POLICY = "logs/rsl_rl/cartpole_direct/<run>/exported/policy.pt"

ACTION_SCALE = 0.5      # 训练时用的 action_scale（位置版，单位米）
KP, KD = 400.0, 40.0    # 训练时的 PD 增益
CTRL_DT = 1.0 / 60.0    # 训练时的控制周期
EPISODE_STEPS = 300     # 5 秒

model = mujoco.MjModel.from_xml_path(MJCF)
data = mujoco.MjData(model)
n_sub = max(1, int(round(CTRL_DT / model.opt.timestep)))

policy = torch.jit.load(POLICY).eval()

# 初始条件：杆偏 0.1 rad（和 Isaac 的 reset 对齐）
data.qpos[0] = 0.0
data.qpos[1] = 0.1
mujoco.mj_forward(model, data)

for step in range(EPISODE_STEPS):
    # ---- 观测：顺序必须和 Isaac 一致：[θ, ω, x, v] ----
    obs = np.array([data.qpos[1], data.qvel[1], data.qpos[0], data.qvel[0]],
                   dtype=np.float32)

    with torch.no_grad():
        a = float(policy(torch.from_numpy(obs).reshape(1, -1)).item())

    # ---- 动作 → 位置目标 → PD → 力 ----
    q_des = a * ACTION_SCALE
    for _ in range(n_sub):
        F = KP * (q_des - data.qpos[0]) - KD * data.qvel[0]
        data.ctrl[0] = np.clip(F, -400, 400)
        mujoco.mj_step(model, data)

    if step % 30 == 0:
        print(f"t={step*CTRL_DT:4.1f}s  x={data.qpos[0]:+.3f}  "
              f"theta={data.qpos[1]:+.3f}  F={data.ctrl[0]:+7.1f}")

    # 终止：与 Isaac 一致
    if abs(data.qpos[1]) > np.pi / 2 or abs(data.qpos[0]) > 3.0:
        print(f"terminated at step {step}: |theta|={abs(data.qpos[1]):.2f}, "
              f"|x|={abs(data.qpos[0]):.2f}")
        break

import numpy as np
from scipy.optimize import least_squares

def simulate(params, u, T, dt=0.001):
    M, m, l, b = params
    x, v, th, w = 0.0, 0.0, np.deg2rad(30), 0.0

T4.1 C 写动力学 + RK4

目的：把倒立摆的方程自己写一遍。写对了，你才真的懂"离散化"和"控制周期"。

前置：T3.4（参数已辨识）。

推导（照这个写，别抄错符号）

设小车质量 $M$、杆质量 $m$、杆质心到关节距离 $l$、小车阻尼 $b$、控制力 $F$，杆角 $\theta$ 从竖直向上量起。拉格朗日方程给出：

$$ (M+m)\ddot x + m l\ddot\theta\cos\theta - m l\dot\theta^2\sin\theta = F - b\dot x $$

$$ m l\ddot x\cos\theta + m l^2\ddot\theta - m g l\sin\theta = 0 $$

解出加速度（这就是你要写的两行）：

$$ \ddot\theta = \frac{(M+m)g\sin\theta - F\cos\theta - m l\dot\theta^2\sin\theta\cos\theta}{l\,(M + m\sin^2\theta)} $$

$$ \ddot x = \frac{F - b\dot x + m l\left(\dot\theta^2\sin\theta - \ddot\theta\cos\theta\right)}{M+m} $$

操作：新建 c/cartpole.c：

#include <stdio.h>
#include <math.h>

typedef struct { double x, v, th, w; } state_t;

static const double G = 9.81, M = 1.0, m = 0.1, l = 0.5, b = 10.0;

static void deriv(const state_t *s, double F, state_t *d)
{
    double st = sin(s->th), ct = cos(s->th);
    double den = l * (M + m * st * st);
    double thdd = ((M + m) * G * st - F * ct - m * l * s->w * s->w * st * ct) / den;
    double xdd = (F - b * s->v + m * l * (s->w * s->w * st - thdd * ct)) / (M + m);

    d->x = s->v;
    d->th = s->w;
    d->v = xdd;
    d->w = thdd;
}

/* 四阶龙格库塔：一步 dt */
static void rk4(state_t *s, double F, double dt)
{
    state_t k1, k2, k3, k4, tmp;

    deriv(s, F, &k1);

    tmp = (state_t){s->x + 0.5*dt*k1.x, s->v + 0.5*dt*k1.v,
                    s->th + 0.5*dt*k1.th, s->w + 0.5*dt*k1.w};
    deriv(&tmp, F, &k2);

    tmp = (state_t){s->x + 0.5*dt*k2.x, s->v + 0.5*dt*k2.v,
                    s->th + 0.5*dt*k2.th, s->w + 0.5*dt*k2.w};
    deriv(&tmp, F, &k3);

    tmp = (state_t){s->x + dt*k3.x, s->v + dt*k3.v,
                    s->th + dt*k3.th, s->w + dt*k3.w};
    deriv(&tmp, F, &k4);

    s->x  += dt/6.0 * (k1.x  + 2*k2.x  + 2*k3.x  + k4.x);
    s->v  += dt/6.0 * (k1.v  + 2*k2.v  + 2*k3.v  + k4.v);
    s->th += dt/6.0 * (k1.th + 2*k2.th + 2*k3.th + k4.th);
    s->w  += dt/6.0 * (k1.w  + 2*k2.w  + 2*k3.w  + k4.w);
}

int main(void)
{
    state_t s = {0.0, 0.0, 0.5236, 0.0};   /* 30° 自由摆 */
    double dt = 1e-3, T = 5.0;

    printf("t,theta,x\n");
    for (int k = 0; k < (int)(T / dt); k++) {
        rk4(&s, 0.0, dt);                   /* 不控制，只看自由摆 */
        if (k % 10 == 0) printf("%.3f,%.6f,%.6f\n", k * dt, s.th, s.x);
    }
    return 0;
}

T4.3 在 C 里跑导出的策略

目的：彻底搞懂"策略就是一个 4→32→32→1 的矩阵乘法"。做完这个，你再也不会觉得神经网络神秘。

第一步 · 把权重导成 C 数组

# c/export_weights.py
import torch, numpy as np

ckpt = torch.load("logs/rsl_rl/cartpole_direct/<run>/model_99.pt", map_location="cpu")
sd = ckpt["model_state_dict"]

for k in sorted(actor): print(k, tuple(actor[k].shape))

然后写进 c/policy_weights.h：

with open("c/policy_weights.h", "w") as f:
    f.write("/* 自动生成，勿手改 */\n")
    for name, key in [("W1","actor.0.weight"), ("B1","actor.0.bias"),
                      ("W2","actor.2.weight"), ("B2","actor.2.bias"),
                      ("W3","actor.4.weight"), ("B3","actor.4.bias")]:
        arr = actor[key].numpy().astype(np.float32)
        flat = arr.reshape(-1)
        f.write(f"static const float {name}[{flat.size}] = {{"
                + ",".join(f"{x:.7f}f" for x in flat) + "};\n")
        f.write(f"static const int {name}_DIM0 = {arr.shape[0]}, {name}_DIM1 = {arr.shape[1] if arr.ndim>1 else 1};\n")

第二步 · C 里前向传播（ELU：$x>0$ 时 $x$，否则 $e^x-1$）

static float elu(float x) { return x > 0 ? x : expf(x) - 1.0f; }

static float policy_forward(const float obs[4])
{
    float h1[32], h2[32], out = B3[0];
    for (int i = 0; i < 32; i++) {
        float acc = B1[i];
        for (int j = 0; j < 4; j++) acc += W1[i * 4 + j] * obs[j];
        h1[i] = elu(acc);
    }
    for (int i = 0; i < 32; i++) {
        float acc = B2[i];
        for (int j = 0; j < 32; j++) acc += W2[i * 32 + j] * h1[j];
        h2[i] = elu(acc);
    }
    for (int j = 0; j < 32; j++) out += W3[j] * h2[j];
    return out;
}

第三步 · 闭环

float obs[4] = { (float)s.th, (float)s.w, (float)s.x, (float)s.v };
float a = policy_forward(obs);
double q_des = a * ACTION_SCALE;          /* 与训练一致，例如 0.5 */
double F = KP * (q_des - s.x) - KD * s.v;

0. 先把四个词分开（否则会一直觉得"差了点"）

你现在的困惑，本质是四个概念被混在一起了。先拆开：

词 它问的问题 它是什么 现在到哪了
AGI 能不能跨任务、跨本体、自己定目标？ 目标（通用性 + 自主性） 远未达到
RSI 能不能改进"自己改进的能力"？ 机制（AGI 的一条路，不是目标） 没做到，只有雏形
世界模型 能不能预测"我做了 A 会怎样"？ 组件（预测器） 单卡能做，机器人上刚起步
自我认知 能不能表征"我是谁、我能做什么、我不知道什么"？ 组件（自模型 + 元认知） 实验室阶段，没有工程范式

关系：

AGI = 通用性 × 自主性
      ├─ 通用性 ← 语言/多模态（组合性）+ 跨本体迁移
      └─ 自主性 ← 世界模型（预测）+ 自我模型（反省）+ 自我改进（进化）
                                  ↑                    ↑
                            你缺的那块           RSI 是它的极端版

所以：

  1. 世界模型不是 RSI 的另一条路线，它是"自主性"里的一块组件。
  2. RSI 不是目标，它是"自我改进"这条机制走到极端的样子。
  3. 你感觉"差了点"，差的是自我模型 + 元认知——世界模型让 agent 会预测外部，自我模型让它会预测自己。

一句话：世界模型让它会"做梦"，自我模型让它会"照镜子"，自我改进让它会"长个"。

1. 你的直觉是对的：它们全是"训练出来的模型"

一个 agent 内部其实有 6 个模型，你现在只训了第 1 个：

# 模型 输入 → 输出 回答什么问题 你有吗
1 策略 $\pi(a\mid s)$ 状态 → 动作 现在该做什么 ✅ PPO 训过
2 价值 $V(s)$ / $Q(s,a)$ 状态 → 回报 这个局面有多好 ✅ 在 PPO 里
3 世界模型 $p(s'\mid s,a)$ 状态+动作 → 下一状态 我这么做会怎样 ❌ 缺
4 奖励模型 $r_\psi(s,a)$ 状态+动作 → 分数 什么算好（学出来的） ❌ 缺
5 自我模型 $f_\theta(\text{我})$ 自身观测+历史 → 我的能力/参数/边界 我是谁、我能做什么 ❌ 缺
6 元模型（学会学习） 任务分布 → 初始参数/超参 我该怎么学得更快 ❌ 缺

你现在做的"Isaac Lab + PPO"，只是在训第 1、2 个。这就是"感觉差了点"的技术原因：能用，但不会想、不会反省、不会自己变强。

2. "能和人交互还有动作" 是什么：VLA，但它只是接口层

你看到的那种"听得懂话、会动"的模型，是 VLA（Vision-Language-Action）：

$$ a_t \sim \pi_\theta\left(a_t \mid o_{\le t},\ \ell\right) $$

它 = 视觉编码器 + 语言模型 + 动作头（离散 token / 回归 / 扩散 / 流匹配）。

但它只解决"会说 + 会做"，不解决"会想 + 会反省"。三层能力要分开看：

层 能力 代表 缺什么
接口层 听得懂、做得对 RT-2、OpenVLA、π0、GR00T N1 不会预测后果
预测层 知道"这么做会怎样" Dreamer、TD-MPC、V-JEPA 2、Cosmos 不会反省自己
反省层 知道自己不知道、能改自己 自模型、元认知、自我改进 没有成熟范式

所以"和人交互 + 有动作"确实是一个训练好的模型，但它是接口，不是智能的全部。

结论：你不需要成为"训大模型的人"，你需要成为"能把大模型接到机器人上、并判断它靠不靠谱的人"。 后者更缺。

4. 五层能力栈（"差的那点"具体在哪）

层 核心问题 可测量的代理指标 单卡能做吗
L0 感知-动作 能不能完成动作 成功率、残差、力矩 RMS ✅ 你现在就在这
L1 世界模型 能不能预测后果 多步预测误差、规划收益 ✅
L2 自我模型 知不知道自己是谁/能做啥 自模型预测误差、参数辨识误差 ✅ 仿真里
L3 元认知 知不知道自己不知道 校准误差 ECE、OOD 检测 AUC、求助率 ✅
L4 自我改进 能不能自己变强 闭环 3 轮的指标斜率 🔶 要真机/高保真仿真
L5 通用性 能不能跨任务/跨本体 零样本迁移成功率 🔶 要多本体数据

关键认知：L2、L3 不是玄学，它们有明确的数学形式。

L2 自我模型：给定自己的动作历史 $a_{1:t}$ 和观测 $o_{1:t}$，预测自身的物理参数或能力：

$$ \hat\phi = f_\theta\left(o_{1:t}, a_{1:t}\right),\qquad \mathcal{L}_{\text{self}} = \left\|\hat\phi - \phi_{\text{true}}\right\|^2 $$

$\phi$ 可以是质量、连杆长度、关节限位、最大力矩、甚至"我能不能完成这个动作"。

L3 元认知（校准）：模型给出的置信度要和真实正确率对齐。期望校准误差：

$$ \mathrm{ECE} = \sum_{b=1}^{B}\frac{|S_b|}{n}\left|\,\mathrm{acc}(S_b) - \mathrm{conf}(S_b)\,\right| $$

一个"有自我认知"的系统，至少要做到：说"我有 70% 把握"时，真的对 70%。

L4 自我改进：闭环

$$ \text{评估} \to \text{找难例} \to \text{采数据} \to \text{重训} \to \text{评估} $$

RSI 是这条闭环自己加速自己的极端版本。

5. 路线：5 个台阶（每台阶 4-8 周）

S1 · 世界模型（会预测）

  • 问题：我这么做会怎样？
  • 做法：DreamerV3 复现 → TD-MPC 式潜空间规划 → 小规模视频世界模型
  • 验收：样本效率优于 PPO 50%；潜空间 MPC 接近真模型 MPC；10 帧视频预测误差曲线
  • 代表：DreamerV3 (2301.04104)、TD-MPC2、V-JEPA 2、Cosmos

S2 · 自我模型（会照镜子）

  • 问题：我是什么形态？我的极限在哪？
  • 做法：在仿真里随机化自己的形态/参数（质量、连杆长度、关节限位、电机强度），让网络从 $(o,a)$ 历史回归这些参数；再做"能力边界"预测（这个动作我能不能做成）
  • 验收：自模型参数误差 < 10%；换形态后 100 步内自适应
  • 代表：Lipson 组的"机器人自建模"（self-modeling machines）、RMA（环境因子估计——本质就是自模型的特例）

S3 · 元认知（知道自己不知道）

  • 问题：我什么时候该求助/该停？
  • 做法：给策略加不确定性估计（集成、MC dropout、分位数），做校准；设计"高不确定就减速/求助"的策略；画"求助率-成功率"曲线
  • 验收：ECE < 0.05；OOD 检测 AUC > 0.9；求助后成功率提升
  • 代表：校准（temperature scaling）、OOD 检测、主动学习

S4 · 自我改进闭环（会进化）

  • 问题：能不能自己变强？
  • 做法：用 S1 的世界模型找"预测会失败"的状态 → 优先采样 → 训练 → 用 S3 的置信度决定要不要回灌 → 跑 3 轮
  • 验收：同一评测集成功率单调上升；有一份"闭环哪步最脆弱"的分析
  • 代表：AlphaZero (1712.01815)、STaR (2203.14465)、RLVR (2501.12948)

S5 · 通用性（跨任务、跨本体、听人话）

  • 问题：换个机器人、换个任务还灵吗？
  • 做法：同一策略在 2-3 个本体上训（cartpole → 四足 → 简单臂）；加语言条件；测零样本迁移
  • 验收：跨本体迁移后成功率 > 60%（不微调）；语言指令换了还能执行
  • 代表：GR-2 (2410.06158)、π0、GR00T N1

顺序不要换：没有 S1 的"预测"，S2 的自模型只是在拟合噪声；没有 S3 的"校准"，S4 的闭环会自己骗自己。

6. "自我认知"到底能不能工程化

要诚实："主观体验"不能工程化，但"自我模型 + 元认知"可以。

你想要的 可工程化的部分 可测指标

指标速查

看不懂某条曲线时翻这里。每条指标：是什么 → 你的正常范围 → 异常怎么办。 数据全部来自你自己的 9 个 run（见 04-实验台账）。

一、六条主指标

指标 是什么 你的正常范围 异常时先查
Train/mean_reward 最近完成回合的平均回报 取决于 alive：1→约 297，2→约 594，5→约 1492 先算 util = reward/(299×alive)，别跨配置比绝对值
Train/mean_episode_length 平均回合长度（上限 299） 收尾 299 卡在 130-150 → 初始状态有一半"第一步就死"（终止条件问题，不是策略问题）
Policy/mean_noise_std 动作分布的标准差 起步 1.0，收尾 0.02-0.05 一直 1.0 → 奖励没区分度；掉太快 → 卡在次优
Loss/value_function critic 的 MSE 0.001-0.04（跟奖励尺度走） 大于 1 → 目标值太大或奖励尺度太野
Loss/surrogate 策略损失，带着 $-\hat A$ 约 $-0.01$ ~ $+0.01$ 越小不代表越好，看有没有剧烈震荡
Loss/learning_rate KL 刹车后的学习率 在 $10^{-5}$ 与 $10^{-2}$ 之间跳 不要读成"衰减"，它反映"这批数据多出人意料"

二、三个容易误读的地方

1. Loss/entropy 是负的很正常。 高斯策略的微分熵（$\sigma$ 是标准差）：

$$ H = \tfrac12\ln\left(2\pi e\,\sigma^2\right) $$

$\sigma < 0.242$ 之后必然为负。你日志里 $\sigma\approx0.035$ 时 $H\approx-1.92$，和 TensorBoard 的 $-1.939$ 对得上。判断探索强弱看 std，别看熵的正负。

2. Loss/learning_rate 不是衰减曲线。 desired_kl = 0.01，实测 KL 超过 $2\times$ 目标就除以 1.5，低于一半就乘 1.5。所以它在地板 $10^{-5}$ 和天花板 $10^{-2}$ 之间来回弹。

3. Episode/Reward/* 分项默认没有。 你这个 Direct 环境只回传标量奖励。要看得自己往 self.extras["log"] 里写（01-教程 第 4 步有改法）。

三、三个诊断流程

A. reward 不涨

  1. util 有没有到 0.99？到了就别看 reward 了，去看 eval。
  2. 回合长度涨不涨？不涨 → 查终止条件（初始分布是否越界）。
  3. std 有没有动？不动 → 查奖励有没有区分度。

B. std 不降

  1. util 是不是已经 1.0（"活下来"就满分）→ 任务太容易，加难度。
  2. entropy_coef 是不是偏大？0.005 时熵项约 0.007，和 surrogate 同量级。
  3. 是不是 policy 项梯度被 clip 吃掉了 → 看 surrogate 是否长期贴 0。

C. 训练指标好、eval 差

  1. eval 用的是确定性动作吗（关噪声）？
  2. eval 的初始条件是否超出训练分布？
  3. 是不是拿了 model_499（末期过拟合到"只站着"）而不是 eval 最好的 checkpoint？

第 1 章 · 值函数：为什么"未来"能用一个数概括

这一节只干一件事：说清楚"价值"是什么，以及为什么它满足一个自己等于自己的方程。

1.1 先说人话

下棋时你说"这个局面好"，其实是在说"从这儿走下去我大概能赢多少分"。价值 = 从这儿出发，未来所有奖励的（折扣）总和，取平均。

为什么要折扣？因为越远的奖励越不确定，而且我们希望早点拿到。折现率 $\gamma$ 就是"未来的钱值多少今天的钱"。

为什么要平均？因为策略定下来后未来仍然是随机的，只能谈期望。

1.2 推给你看

一条轨迹的总回报：

$$ G_t = r_{t+1} + \gamma r_{t+2} + \gamma^2 r_{t+3} + \cdots $$

关键一步——拆成"这一步 + 剩下的"：

$$ G_t = r_{t+1} + \gamma G_{t+1} $$

两边对"从现在开始随机走"取期望（$\gamma$ 是常数，可以提出来）：

$$ \boxed{\,V^\pi(s) = \sum_a \pi(a\mid s)\sum_{s'} P(s'\mid s,a)\left[R(s,a,s') + \gamma V^\pi(s')\right]\,} $$

逐项读一遍：外层对动作求和（策略在选动作），内层对下一个状态求和（环境在掷骰子），方括号是"这一步的奖励 + 折扣后的未来价值"。

这行就是贝尔曼期望方程。它的意义：无穷长的期望被压缩成一个方程。值迭代、TD、Q-learning 都在解它。

最优版本把"按策略平均"换成"挑最好的动作"：

$$ V^*(s) = \max_a \sum_{s'} P(s'\mid s,a)\left[R + \gamma V^*(s')\right] $$

这个 $\max$ 就是"非线性"的来源。有它不能直接求逆解；没它（只评估固定策略）就是一个线性方程组：

$$ (I - \gamma P^\pi)\,V^\pi = R^\pi $$

1.3【例题】我带你走一遍

两状态 $\{A, B\}$，两个动作：

  • stay：得 $+1$，留在原地；
  • switch：得 $0$，跳到另一个状态。

$\gamma = 0.9$。求 $V^*(A)$、$V^*(B)$。

解法：先写最优方程（奖励只和动作有关）：

$$ V^*(A) = \max\{1 + 0.9 V^*(A),\ 0 + 0.9 V^*(B)\} $$

两边结构完全对称，先猜 $V^*(A) = V^*(B) = V$。代 stay 分支：

$$ V = 1 + 0.9 V \;\Rightarrow\; V = 10 $$

再用 $V = 10$ 检查 switch 分支：$0 + 0.9 \times 10 = 9 < 10$，所以 stay 确实更好。

答：$V^*(A) = V^*(B) = 10$，最优策略是永远 stay。

套路（对称 → 猜 → 代回验证另一分支）是手算贝尔曼的标准姿势。

第 2 章 · 策略梯度：为什么可以直接对"期望"求导

这一节只干一件事：把"调高好动作的概率"变成能算的公式。

2.1 先说人话

训练就三句：

  1. 用现在的策略跑一批轨迹；
  2. 看哪些动作后面跟着高回报；
  3. 把这些动作的概率调高一点。

第三句有麻烦：动作概率变了，采样的轨迹也跟着变。相当于"我在改考题，同时又要按新考题算平均分"。直接对期望求导会卡在这里。

解决它只需一个高中技巧：$\frac{d}{dx}\log f = \frac{f'}{f}$，即 $f' = f \cdot (\log f)'$。

2.2 推给你看

目标 $J(\theta) = \mathbb{E}_{\tau \sim \pi_\theta}[R(\tau)]$。

第一步，写轨迹概率（$\rho_0$ 是初始状态分布，$P$ 是环境转移）：

$$ p_\theta(\tau) = \rho_0(s_0)\prod_t \pi_\theta(a_t\mid s_t)\,P(s_{t+1}\mid s_t,a_t) $$

盯住这里：$\rho_0$ 和 $P$ 都不含 $\theta$。这是整章成立的根本原因。

第二步，把"对分布求导"换成"对 log 求导"：

$$ \nabla_\theta J = \int \nabla_\theta p_\theta(\tau) R(\tau)\,d\tau = \int p_\theta(\tau)\,\nabla_\theta \log p_\theta(\tau)\,R(\tau)\,d\tau = \mathbb{E}\left[\nabla_\theta \log p_\theta(\tau)\,R(\tau)\right] $$

第三步，取 log 后乘积变加法，只有策略项含 $\theta$：

$$ \nabla_\theta \log p_\theta(\tau) = \sum_t \nabla_\theta \log \pi_\theta(a_t\mid s_t) $$

第四步，因果性：$t$ 时刻的动作不可能影响 $t$ 之前的奖励，所以整条轨迹的回报 $R(\tau)$ 可以换成"从 $t$ 往后的回报" $G_t$：

$$ \boxed{\;\nabla_\theta J = \mathbb{E}\left[\sum_t \nabla_\theta \log \pi_\theta(a_t\mid s_t)\,G_t\right]\;} $$

2.3 为什么可以减掉一个"基准"

设 $b(s)$ 只跟状态有关。因为

$$ \sum_a \nabla_\theta \pi_\theta(a\mid s) = \nabla_\theta \sum_a \pi_\theta(a\mid s) = \nabla_\theta 1 = 0 $$

所以

$$ \mathbb{E}_{a}\left[\nabla_\theta \log \pi_\theta(a\mid s)\, b(s)\right] = b(s)\sum_a \nabla_\theta \pi_\theta(a\mid s) = 0 $$

结论：把 $G_t$ 换成 $G_t - b(s_t)$，期望不变，方差变小。这就是"优势函数"的由来。

⚠ $b$ 只能依赖状态。依赖动作的话，上面求和不为 0，会引入偏差。

2.4【例题】我带你走一遍

高斯策略 $\pi(a\mid s) = \mathcal{N}(\mu_\theta(s), \sigma^2)$，且 $\mu = \theta$、$\sigma$ 固定。

$$ \log \pi = -\frac{(a-\theta)^2}{2\sigma^2} - \log(\sigma\sqrt{2\pi}) \;\Rightarrow\; \nabla_\theta \log \pi = \frac{a-\theta}{\sigma^2} $$

于是

$$ \nabla_\theta J = \mathbb{E}\left[\frac{a-\theta}{\sigma^2}\,A(s,a)\right] $$

读法：$A > 0$（动作比平均好）时，梯度把 $\theta$ 往 $a$ 推；$A < 0$ 时反向。分母 $\sigma^2$：策略越确定，同样的偏差给越大的梯度。

第 3 章 · GAE：一个"偏差 ↔ 方差"的旋钮

这一节只干一件事：说清 $\lambda$ 在调什么，以及为什么 $\lambda = 1$ 必须和蒙特卡洛算出来一模一样。

3.1 先说人话

要估"这个动作比平均好多少"（优势），有两种估法：

  • 只看一步：$r + \gamma V(s') - V(s)$。用了估出来的 $V$ → 有偏差，但只含一步随机性 → 方差小。
  • 看完整回合：$G_t - V(s_t)$。回报是真的（无偏），但要累加很多随机奖励 → 方差大。

GAE 用旋钮 $\lambda$ 在两者之间连续调节：

$$ A_t^{\mathrm{GAE}} = \sum_{l=0}^{\infty}(\gamma\lambda)^l\,\delta_{t+l}, \qquad \delta_t = r_t + \gamma V(s_{t+1}) - V(s_t) $$

  • $\lambda = 0$：只剩 $\delta_t$（一步 TD）。
  • $\lambda = 1$：所有 $\delta$ 都用上 → 望远镜求和后正好等于 $G_t - V(s_t)$。

3.2【例题】我带你走一遍（一定要手算）

3 步轨迹：$r = [1, 0, 2]$，$V = [5, 4, 3]$，第 3 步之后终止（$V(s_3)=0$），$\gamma = 0.9$。

先算每步 TD 残差：

$$ \begin{aligned} \delta_0 &= 1 + 0.9\times 4 - 5 = -0.4\\ \delta_1 &= 0 + 0.9\times 3 - 4 = -1.3\\ \delta_2 &= 2 + 0 - 3 = -1.0 \end{aligned} $$

  • $\lambda = 0$：$A_0 = \delta_0 = -0.4$
  • $\lambda = 1$：$A_0 = -0.4 + 0.9(-1.3) + 0.81(-1.0) = -2.38$

核对：蒙特卡洛 $G_0 = 1 + 0.9\times0 + 0.81\times2 = 2.62$，$A_0 = 2.62 - 5 = -2.38$ ✅

你自己实现的 GAE，如果 $\lambda=1$ 时对不上蒙特卡洛，一定是终止处理或折扣写错了。

第 4 章 · PPO：为什么 clip 能"限速"

这一节只干一件事：说清 clip 剪的是什么（不是动作！），以及为什么它能防止更新太猛。

4.1 先说人话

PPO 想用"旧策略采的数据"多学几遍（省样本），但学太多会崩。

它的办法很土：一次更新里，如果新策略和旧策略差太多，就不许再往那个方向走。 具体是给"概率比" $r_t(\theta) = \dfrac{\pi_\theta(a_t\mid s_t)}{\pi_{\text{old}}(a_t\mid s_t)}$ 划两条线：$1-\epsilon$ 和 $1+\epsilon$。

4.2 推给你看

$$ L^{\mathrm{CLIP}}(\theta) = \mathbb{E}\left[\min\left(r_t(\theta)\hat{A}_t,\ \mathrm{clip}\left(r_t(\theta), 1-\epsilon, 1+\epsilon\right)\hat{A}_t\right)\right] $$

分两种情况（$\epsilon = 0.2$）：

  • $\hat A > 0$（动作好，想提高概率）：$r$ 超过 $1.2$ 后 $\mathrm{clip}$ 把它钉在 $1.2$，$\min$ 取常数 → 梯度为 0。
  • $\hat A < 0$（动作差，想降低概率）：$r$ 低于 $0.8$ 后同样被钉住 → 梯度为 0。

两个方向都封顶，所以 $L^{\mathrm{CLIP}}$ 永远 $\le$ 原始目标，是它的悲观下界。优化下界，最多让真实性能差一点点——这就是便宜的"信赖域"。

$$ L(r)=\begin{cases} r, & r \le 1.2\\ 1.2, & r > 1.2\end{cases} $$

（$r<0.8$ 时 $\min(r,0.8)=r$，仍是 $r$。）所以 $r > 1.2$ 那段梯度为 0。

第 5 章 · 熵与 SAC：为什么故意保留随机性

这一节只干一件事：解释 Loss/entropy 为什么会是负数，以及 SAC 的熵在奖励什么。

5.1 先说人话

策略太早变"死"（只做一个动作）会卡住。所以要给它一点"保留随机"的奖励。测随机性的量叫熵。

高斯策略的熵有闭式解：

$$ H(\pi) = \tfrac12 \ln\left(2\pi e\,\sigma^2\right) $$

关键：$\sigma < 0.242$ 之后 $\ln(\cdot)$ 变负。所以 Loss/entropy 是负数完全正常，它只是熵的值，不是 loss 爆炸。

你日志里 $\sigma \approx 0.035$ 时 $H \approx -1.92$，和 TensorBoard 的 $-1.939$ 对得上。这是你"读懂指标"的第一个实证。

5.2 SAC 在干什么

SAC 把目标从"奖励最大"改成"奖励 + 熵最大"：

$$ J(\pi) = \mathbb{E}\left[\sum_t r_t + \alpha H(\pi(\cdot\mid s_t))\right] $$

对应的"软贝尔曼方程"把 $\max$ 换成平滑版：

$$ V(s) = \alpha \ln \sum_a \exp\frac{Q(s,a)}{\alpha} $$

当 $\alpha \to 0$ 时右边趋于 $\max_a Q$，退化成普通 RL。所以 SAC 是最优化的光滑版本——光滑了梯度才好使。

1999 年 Ng 等人给了"安全"加法：只加势函数之差。

$$ F(s,a,s') = \gamma\Phi(s') - \Phi(s) $$

7.2 为什么安全（望远镜求和）

$$ \sum_t \gamma^t\left(\gamma\Phi(s_{t+1}) - \Phi(s_t)\right) = -\Phi(s_0) + \lim_{T\to\infty}\gamma^T\Phi(s_T) $$

若 $\gamma < 1$ 且 $\Phi$ 有界，最后一项为 0。所以每条轨迹的回报只差常数 $-\Phi(s_0)$——与策略无关，排序不变，最优策略不变。

朝 0 走（$|x'|<|x|$）时 $F>0$；远离时为负。理论上不改变最优策略。

第 1 章 · 离散化：为什么改 decimation 等于换了一个任务

这一节只干一件事：说清"仿真步长"和"控制周期"不是一回事，以及为什么改控制周期会改变学习难度。

1.1 先说人话

仿真器每 $1/120$ 秒算一次物理，但策略不是每步都出新动作——它每两个物理步才出一次（decimation = 2）。

也就是说：策略说一句话，电机要执行两拍。 这两拍之间动作保持不变，这叫零阶保持（ZOH）。

1.2 推给你看

连续系统 $\dot x = Ax + Bu$ 的解：

$$ x(t) = e^{At}x(0) + \int_0^t e^{A(t-\tau)}Bu(\tau)\,d\tau $$

为什么是这个解（积分因子技巧）：把 $e^{-At}x$ 求导，

$$ \frac{d}{dt}\left(e^{-At}x\right) = e^{-At}\dot x - Ae^{-At}x = e^{-At}(Ax+Bu) - Ae^{-At}x = e^{-At}Bu $$

两边从 $0$ 到 $t$ 积分，左乘 $e^{At}$，就得到上面的解。

零阶保持（$u$ 在 $[kT,(k+1)T)$ 内不变）：

$$ A_d = e^{AT}, \qquad B_d = \int_0^T e^{A\tau}B\,d\tau $$

所以你改 decimation，改的是 $T$，也就改了 $A_d, B_d$。 同样的策略，在世界里"推的时长"变了，行为当然变。

1.3【例题】

一阶系统 $\dot x = -ax + bu$。求 $T$ 下的 $A_d, B_d$，并说明 $T \to 0$ 的极限。

$$ A_d = e^{-aT},\qquad B_d = \int_0^T e^{-a\tau}b\,d\tau = \frac{b}{a}\left(1 - e^{-aT}\right) $$

$T\to0$ 时 $A_d \to 1-aT$、$B_d \to bT$，就是欧拉法 $x_{k+1} = x_k + T(-ax_k + bu_k)$。

结论：欧拉离散化只是 ZOH 的一阶近似。控制周期大时用它会算错极点（虚假的不稳定）。

第 2 章 · LQR：它其实是"二次型问题里的 RL"

这一节只干一件事：从"代价最小"推一遍 Riccati 方程，并说清它和 RL 的关系。

2.1 先说人话

LQR 问的是：每一步都同时惩罚"状态偏差"和"用力大小"，怎么用力最省？

因为代价是二次的、系统是线性的，最优解一定是"状态乘一个矩阵"（线性反馈）。这个结论不是假设，是推出来的。

2.2 推给你看

代价

$$ J = \int_0^\infty \left(x^\top Qx + u^\top Ru\right)dt $$

猜值函数是二次型 $V(x) = x^\top Px$（为什么能猜？因为二次代价 + 线性系统 → 值函数仍是二次的）。代入 HJB：

$$ 0 = \min_u\left[x^\top Qx + u^\top Ru + \nabla V^\top (Ax+Bu)\right] $$

对 $u$ 求导令零（$\nabla V = 2Px$）：

$$ 2Ru + 2B^\top Px = 0 \;\Rightarrow\; \boxed{\,u^* = -R^{-1}B^\top P\,x\,} $$

代回去，得到代数 Riccati 方程：

$$ \boxed{\,A^\top P + PA - PBR^{-1}B^\top P + Q = 0\,} $$

和 RL 的关系（面试常问）：把 $-J$ 看成回报、$V=x^\top Px$ 看成 critic、$u=-Kx$ 看成 actor，那 LQR 就是"已知精确模型 + 二次型值函数 + 线性策略"的解析 RL。区别只有两条：RL 不知道 $A,B$；RL 不限定值函数形式。

稳定性：取 $V = x^\top Px$ 当 Lyapunov 函数，

$$ \dot V = x^\top(A^\top P + PA)x = -x^\top\left(Q + PBR^{-1}B^\top P\right)x < 0 $$

所以闭环一定稳定——这不是调参调出来的，是 Riccati 方程保证的。

2.3【例题】

标量系统 $\dot x = u$，代价 $\int (qx^2 + ru^2)dt$。

Riccati（此时 $A=0, B=1$）：

$$ 0 = -P^2/r + q \;\Rightarrow\; P = \sqrt{qr} $$

$$ K = R^{-1}B^\top P = \frac{\sqrt{qr}}{r} = \sqrt{\frac{q}{r}} \;\Rightarrow\; u = -\sqrt{\frac{q}{r}}\,x $$

读法：$q/r$ 越大越激进。$q$ 是"多在乎偏差"，$r$ 是"多在乎耗能"。

第 3 章 · 观测器：为什么"估计"和"控制"能分开设计

这一节只干一件事：说清分离原理，以及为什么它在 RL 里仍然有用。

3.1 先说人话

控制器要的是"现在状态是什么"，但传感器只给你一部分。于是先造一个"虚拟状态" $\hat x$，让它追着真实状态跑——这就是观测器。

Luenberger 观测器：

$$ \dot{\hat x} = A\hat x + Bu + L\left(y - C\hat x\right) $$

3.2 推给你看

令误差 $e = x - \hat x$，两式相减：

$$ \dot e = (A - LC)e $$

所以只要选 $L$ 让 $A-LC$ 的极点都在左半平面，$e \to 0$。 这就是全部。

分离原理：用 $\hat x$ 做反馈 $u = -K\hat x$，闭环极点是

$$ \mathrm{eig}(A-BK)\ \cup\ \mathrm{eig}(A-LC) $$

也就是说：可以先设计控制器（假设状态可测），再单独设计观测器，互不影响。

这条只对线性系统成立。非线性系统里，估计误差会通过非线性控制律耦合回来，可能激励未建模动态。

在 RL 里怎么用： 1. 观测缺项（速度、接触）→ 用观测器补； 2. 域随机化下估计环境参数（RMA 的"环境因子"估计器本质就是观测器）； 3. 延迟补偿（用观测器预测当前状态）。

第 4 章 · MPC：为什么"滚动优化"能保证稳定

这一节只干一件事：说清终端代价为什么是关键，以及 MPC 和 LQR 到底是什么关系。

4.1 先说人话

MPC 是"走一步看 N 步"：每次解一个 N 步的最优控制问题，只执行第一步，下一步重新解。

问题来了：每步都重新解，凭什么保证稳定？ 答案藏在"终端代价"里。

4.2 推给你看

优化问题：

$$ \min_{u_0,\dots,u_{N-1}} \sum_{k=0}^{N-1}\left(x_k^\top Qx_k + u_k^\top Ru_k\right) + x_N^\top P_f x_N $$

设最优值为 $V_N(x)$。关键不等式（拿 $x_{k+1}$ 重新解一次，至少不比"沿用旧解"更差）：

$$ V_N(x_{k+1}) \le V_N(x_k) - \left(x_k^\top Qx_k + u_k^\top Ru_k\right) < V_N(x_k) $$

所以 $V_N$ 是一个 Lyapunov 函数 → 闭环渐近稳定。

注意：这个不等式依赖 $P_f$ 选得"够大"（通常取 Riccati 解 $P$），否则最后一步的价值被低估，稳定性就没了。这就是"终端代价 $P_f=0$ 可能不稳定"的原因。

与 LQR 的关系：$N\to\infty$ 且 $P_f = P$（Riccati 解）时，MPC 的解收敛到 LQR。所以：

$$ \text{MPC} = \text{LQR} + \text{约束} + \text{滚动} $$

4.3【例题】

一维系统 $x_{k+1} = x_k + u_k$，$N=2$，$Q=1, R=1$，终端代价为 0。求最优 $u_0$。

倒推：$V_2(x)=0$；$V_1(x) = \min_u (x^2+u^2) = x^2$（取 $u=0$）。

$$ V_0(x) = \min_u\left[x^2+u^2 + (x+u)^2\right] $$

对 $u$ 求导：$2u + 2(x+u) = 0 \Rightarrow u = -x/2$。

第 5 章 · 滑模与自适应：鲁棒性的两种来源

这一节只干一件事：说清 SMC 的鲁棒性从哪来、MRAC 为什么不保证参数收敛，以及它们和 RMA 的对应。

5.1 先说人话

  • 滑模：不管你怎么扰动，我都用"符号函数"把你硬推回一条线上。鲁棒性来自"对扰动上界做假设"。
  • 自适应：我不知道参数，但我边跑边改。鲁棒性来自"在线学习"。

5.2 推给你看

滑模面 $s = \dot e + \lambda e$，取 Lyapunov 函数 $V = \tfrac12 s^2$，要求到达条件：

$$ s\dot s < 0 $$

对 $\ddot x = u + d(t)$（$|d| \le D$），取 $u = \ddot x_d - \lambda\dot e - k\,\mathrm{sign}(s)$，则

$$ s\dot s = s\left(d - k\,\mathrm{sign}(s)\right) \le |s|(D - k) $$

所以 $k > D$ 就能有限时间到达。

为什么必然抖振：$\mathrm{sign}$ 在 $s=0$ 附近硬切换，而真实系统有采样、延迟、高频未建模动态 → 状态在滑模面附近反复穿越。这是结构性的，调参消不掉。

MRAC 的自适应律（Lyapunov 反推）：取 $V = e^\top Pe + \tfrac12 \tilde\theta^\top\Gamma^{-1}\tilde\theta$，令 $\dot V \le 0$ 中的交叉项为零，得到 $\dot\theta = -\Gamma B^\top P e\,x^\top$。

只保证有界，不保证收敛到真值：因为 $\dot V \le 0$ 只给出 $e \in L_2$，参数可能一直漂。要收敛得加持续激励（PE）条件。

第 6 章 · 机械臂：雅可比、静力与"为什么工业界用位置 + PD"

关节转一点，末端动多少？这个"换算表"就是雅可比。它有两副面孔：

6.2 推给你看（平面 2R 臂）

第 2 章 · 模仿学习为什么会在"自己的错误"上崩

这一节只干一件事：搞懂 $O(\varepsilon T^2)$ 是怎么来的，以及为什么多峰数据会把回归"平均"到沟里。

2.1 先说人话

行为克隆（BC）就是"看着专家做，学着他做"。训练时你只见过专家走的路；一旦你自己偏了一点，就进入了"专家没去过的状态"，而那里你没有正确答案 → 越偏越远。

2.2 推给你看

设单步犯错概率 $\varepsilon$，回合长度 $T$。

  • BC 的期望代价是 $O(\varepsilon T^2)$：每一步都可能"出轨"，而出轨后没有恢复能力，误差像 $T^2$ 一样累积。
  • DAgger（让专家在线纠正学生的错误）是 $O(\varepsilon T)$：因为学生见过的状态分布被"修正"了。

为什么 BC 会把多峰动作"平均"掉：若同一观测下有两个合理动作（绕左/绕右），高斯似然的均值恰好在正中间——而正中间可能是障碍物。

2.3【例题】

一条走廊，左右都能绕过去。用单峰高斯做 BC，会输出什么？为什么危险？

答：均值 ≈ 0（正中间），等于"直冲"；同时方差被两侧数据拉大，动作会抖。这就是 diffusion/flow 存在的理由：它们能表示多个峰。

第 4 章 · Diffusion Policy：它到底在学什么

这一节只干一件事：写出训练目标和采样过程，并算清"推理有多慢"。

4.1 推给你看

前向加噪（$\bar\alpha_k$ 是累积系数）：

$$ a_k = \sqrt{\bar\alpha_k}\,a_0 + \sqrt{1-\bar\alpha_k}\,\varepsilon, \qquad \varepsilon \sim \mathcal{N}(0, I) $$

网络学"预测噪声"：

$$ \mathcal{L} = \mathbb{E}_{k,\,a_0,\,\varepsilon}\left[\left\|\varepsilon - \varepsilon_\theta\left(a_k, k, o\right)\right\|^2\right] $$

采样：从纯噪声 $a_K$ 开始，迭代去噪 $K$ 次。

为什么能多峰：它建模的是整个分布 $p(a\mid o)$，采样落在哪个峰由噪声决定；而回归只给均值。

代价：$K$ 次前向。$K=100$、每次 10 ms → 1 秒一次，真机根本不够用。所以实际用"少步 + 动作 chunk"。

4.2【例题】

答：$100\times10\,\text{ms} = 1\,\text{s}$；$T_a=8$ 步 @ 50 Hz = 160 ms 重算一次。所以必须靠 chunk 摊薄成本。

第 5 章 · Flow Matching：为什么能"少步"

这一节只干一件事：说出 flow matching 与 diffusion 的本质差别，并解释"路径直 → 步数少"。

5.1 推给你看

不学去噪，学速度场，把噪声"流"到动作：

$$ \frac{dx}{dt} = v_\theta(x, t, o),\qquad x(0)\sim\mathcal{N}(0,I),\quad x(1)=a $$

训练时用直线路径插值：

$$ x_t = (1-t)\,\varepsilon + t\,a \;\Rightarrow\; \text{目标速度} = a - \varepsilon $$

$$ \mathcal{L} = \mathbb{E}\left[\left\|v_\theta(x_t, t, o) - (a-\varepsilon)\right\|^2\right] $$

采样用欧拉积分 $x \leftarrow x + v_\theta(x,t)\Delta t$，10 步就够。

为什么少步：数值积分的一步误差正比于路径曲率乘 $\Delta t^2$。路径接近直线（曲率≈0）时，大步也准。

二、判断并说明理由（每题 3 分：判断 1 分 + 理由 2 分）

1. 错。 减基线的原理不是"数值变小"，而是 E_{a~π}[∇_θ log π_θ(a|s)] = ∇_θ Σ_a π_θ = ∇_θ 1 = 0，所以任意只依赖状态的基线都不改变期望，但能降低方差。

3. 错（不一定）。 ε 小 → 每步允许的更新更小 → 更稳，但样本效率下降，可能长时间卡在局部最优；ε 太小还会让 clip 频繁触发、梯度大量为 0。稳定性与效率是权衡，不是单调关系。

5. 错。 观测器极点过快会放大测量噪声（L 大 → 噪声直接进估计），且可能激励未建模高频动态；实际要权衡"收敛速度 vs 噪声敏感度"，还要考虑采样频率（离散化后过快极点会失稳）。

三、推导（每题 8 分）

1. 策略梯度定理（给分点 2+2+2+2）

p_θ(τ) = ρ_0(s_0) Π_t π_θ(a_t|s_t) P(s_{t+1}|s_t,a_t) —— 2 分

∇_θ J = ∫ ∇_θ p_θ R dτ = ∫ p_θ ∇_θ log p_θ · R dτ = E[∇_θ log p_θ · R] —— 2 分 （log-derivative trick：∇p = p∇log p）

取对数后 log p_θ = log ρ_0 + Σ_t log π_θ + Σ_t log P，其中 ρ_0 与 P 不含 θ，梯度为 0，故 ∇_θ log p_θ = Σ_t ∇_θ log π_θ(a_t|s_t) —— 2 分

因果性：a_t 不影响 t 之前的奖励，所以 E[∇log π(a_t|s_t)·r_{t'}] = 0 (t' < t)，可把 R(τ) 换成 G_t = Σ_{t'≥t} γ^{t'-t} r_{t'} —— 2 分

减基线：E_{a}[∇log π(a|s)b(s)] = b(s)Σ_a ∇π(a|s) = b(s)∇1 = 0，故可用 G_t - b(s_t)，期望不变、方差下降。

总式：∇_θ J = E[Σ_t ∇_θ log π_θ(a_t|s_t)(G_t - b(s_t))]

2. GAE λ=1 = MC（给分点 4+4）

$A_t^{\mathrm{GAE}} = \sum_{l\ge0}(\gamma\lambda)^l\,\delta_{t+l}$，其中 $\delta_t = r_t + \gamma V(s_{t+1}) - V(s_t)$ —— 4 分

$\lambda=1$ 时展开：

$$ \sum_{l\ge0}\gamma^l\left[r_{t+l} + \gamma V(s_{t+l+1}) - V(s_{t+l})\right] = \sum_{l\ge0}\gamma^l r_{t+l} + \sum_{l\ge0}\gamma^{l+1}V(s_{t+l+1}) - \sum_{l\ge0}\gamma^l V(s_{t+l}) $$

后两项逐项相消（望远镜求和），只剩 $-V(s_t)$（终止时 $V(s_T)=0$）：

$$ = G_t - V(s_t) \qquad\text{—— 4 分} $$

3. 标量 LQR 的 Riccati（给分点 3+2+3）

HJB：$0 = \min_u\left[qx^2 + ru^2 + V_x(ax+bu)\right]$，猜 $V = px^2$，$V_x = 2px$ —— 3 分

对 $u$ 求导：$2ru + 2pxb = 0 \Rightarrow u^* = -\dfrac{pb}{r}x$ —— 2 分

代回：

$$ qx^2 + \frac{p^2b^2}{r}x^2 + 2apx^2 - 2\frac{p^2b^2}{r}x^2 = 0 \;\Longrightarrow\; 2ap - \frac{b^2}{r}p^2 + q = 0 \qquad\text{—— 3 分} $$

即 $u = -Kx$，$K = \dfrac{pb}{r}$。与矩阵形式 $A^\top P + PA - PBR^{-1}B^\top P + Q = 0$ 一致。

4. PPO clip 的梯度（给分点 4+4）

r > 1+ε 时 clip(r,1-ε,1+ε) = 1+ε，A>0 时 (1+ε)A 是常数，min(rA, (1+ε)A) = (1+ε)A（因为 rA > (1+ε)A） —— 4 分

所以 L^CLIP 在该区间是常数，∂L/∂r = 0。这限制的是"让好动作概率继续增大"这一侧（reward-increasing side），防止一次更新把某个动作概率推得过高。

四、计算（每题 6 分：式子 3 分 + 结果 3 分）

1. 两状态 MDP

V(A) = max{1 + 0.9V(A), 2 + 0.9V(B)}，V(B) 对称。

  • 若 stay 最优：V = 1/(1-0.9) = 10；
  • 若 switch 最优：V = 2 + 0.9V → V = 20。

比较：switch 给 20 > stay 给 10 → V*(A)=V*(B)=20，最优策略是永远 switch。 检验：2 + 0.9×20 = 20 ✅，且 1 + 0.9×20 = 19 < 20 ✅。

2. 三步 GAE

δ_0 = 1 + 0.9×4 - 5 = -0.4 δ_1 = 0 + 0.9×3 - 4 = -1.3 δ_2 = 2 + 0 - 3 = -1

五、简答（每题 5 分）

1. alive 放大 5 倍为什么不会"快 5 倍"（给分点 3+2）

advantage 是相对量：A(s,a) = Q(s,a) - V(s)。alive 是每步常数，它在 Q 和 V 里同时出现，相减时被抵消（更严格地说，PPO 还做两次归一化 (A-mean)/std，常数项在减均值时直接消失）。

所以放大 alive 不改变"哪个动作更好"的排序，只改变数值尺度（进而影响 critic 目标、KL、lr 刹车）。真正决定学得快慢的是"惩罚项/终止项提供的相对信号"，不是常数奖励的绝对值。

→ 3 分：指出 advantage 相减抵消；2 分：指出归一化也消除尺度。

2. 内环 PD + 外环 RL（每条 1.7 分）

  1. 稳定性：PD 提供阻尼，抑制高频振荡；策略只需负责低频决策，误差不会直接变成大幅力矩。
  2. 动作空间：位置目标幅值有界、物理意义明确，探索更安全；力矩输出容易饱和/发散。
  3. sim2real：PD 是"模型无关"的快速反馈，能吃掉一部分模型误差与延迟；学习策略的推理延迟不进入内环。

3. 分离原理（给分点 3+2）

内容：线性系统 ẋ = Ax + Bu, y = Cx 下，u = -Kx̂（x̂ 由 Luenberger 观测器给出）的闭环极点 = eig(A-BK) ∪ eig(A-LC)。所以控制器和观测器可以独立设计。

成立条件：系统线性、观测器线性、无噪声/或噪声统计已知。

非线性下不成立：估计误差 e = x - x̂ 会进入非线性控制律，与状态耦合（不是简单的极点叠加），可能激励未建模动态而失稳。

B 卷答案

一、系统设计（20 分：观测 4 + 奖励 8 + 终止 3 + 评估 3 + 冲突 2）

观测（4 分）：o = [θ (rad), ω (rad/s), x (m), v (m/s), (x* - x) (m)]，5 维。用差值而不是 x* 绝对值：数学等价，但省掉网络一次减法，收敛更快。

奖励（8 分）：每项都要有公式 + 量纲 + 典型量级。

$$ \begin{aligned} r_{\text{alive}} &= 1.0\,(1-\text{terminated}), & \text{无量纲} &\sim 1\\ r_{\text{pole}} &= -1.0\,\theta^2, & \mathrm{rad}^2 &\sim 0.001\text{-}0.05\\ r_{\text{target}} &= -1.0\,\min\left(1, (x-x^*)^2\right), & \mathrm{m}^2 &\sim 0\text{-}1\\ r_{\text{cart\_}v} &= -0.01\,|v|, & \mathrm{m/s} &\sim 0.001\text{-}0.01\\ r_{\text{pole\_}v} &= -0.005\,|\omega|, & \mathrm{rad/s} &\sim 0.001\text{-}0.01 \end{aligned} $$

评估（3 分）：x* ∈ {-2,-1,0,1,2} × θ0 ∈ {-0.3π,-0.2π,0,0.2π,0.3π}，每格 32 env，动作取均值（确定性），指标：到位率（|x-x*|<0.1 且未终止）、平均残差角、力矩 RMS。

冲突（2 分）：r_target 和 r_pole 打架——为了到目标必须移动，移动会让杆子倒。用势函数解决：F = γΦ(s') - Φ(s)，Φ = -0.5k(x-x*)²，理论上不改变"保持竖直"的最优策略，只加速"靠近目标"的学习。

二、编程（20 分：代码 10 + 说明 6 + 自测 4）

import numpy as np

def compute_gae(rewards, values, dones, gamma=0.99, lam=0.95, last_value=0.0):
    T = len(rewards)
    adv = np.zeros(T, dtype=np.float64)
    ret = np.zeros(T, dtype=np.float64)
    next_value = float(last_value)
    gae = 0.0
    for t in reversed(range(T)):
        not_done = 1.0 - float(dones[t])
        delta = rewards[t] + gamma * not_done * next_value - values[t]
        gae = delta + gamma * lam * not_done * gae
        adv[t] = gae
        ret[t] = gae + values[t]
        next_value = values[t]
    return adv, ret

为什么从后往前（6 分）：GAE 的定义是"未来 TD 残差的折扣和"，是后向递推 A_t = δ_t + γλA_{t+1}；正向无法写（需要未来信息）。同时 next_value 要从最后一步往前更新。

终止 vs 超时：dones=1 时 not_done=0 → delta = r - V、gae = delta，不 bootstrap。但严格说，超时（truncated）应该 bootstrap：此时 episode 只是被截断，真实价值不为 0。若 dones 里混了超时，需要单独传 truncated 并令 last_value = V(s_T)。这是最常见的实现 bug。

自测（4 分）：用 A 卷四.2 的数据 r=[1,0,2], V=[5,4,3], dones=[0,0,1], γ=0.9, λ=0.95，应得 adv[0] = -2.2425，ret[0] = 2.7575。

三、曲线诊断（每题 6-7 分：原因 4 + 验证 2-3）

A：训练指标很好，eval 只有 40%

最可能原因：训练指标是"训练分布上的随机策略滑动平均"，而 eval 是"确定性动作 + 指定初始角"。训练时策略带噪声（std 到 330 轮才降到 0.2），噪声掩盖了"边缘初始角下的失败"；一旦去掉噪声，边缘条件就暴露。

验证：① 用同一组初始角做 eval，对比"确定性 vs 随机采样"成功率；② 扫初始角网格（0 → ±0.3π）看成功率曲线；③ 检查训练初始分布是否真的覆盖 ±0.3π。

验证：① 把初始分布加难（±0.4π）或加动作惩罚，让"做得好"有区分度，观察 std 是否下降；② 把 entropy_coef 从 0.005 提到 0.05 看 std 下降是否变快（若变快，说明是熵项主导）。

四、原理（每题 5 分）

1. MPC vs RL 的判据

选 MPC：模型可得且较准、有硬约束（力矩/位置/安全）、需要可解释/可验证、实时性可通过 QP 满足。 选 RL：模型难建（接触、摩擦、变形）、需要从数据学复杂行为、任务用奖励描述比用模型描述容易、可接受仿真训练成本。 判据不是"哪个先进"，而是"模型误差 vs 数据量"：模型准 → MPC；数据多且模型不准 → RL；两者都有 → 残差学习/学习型 MPC。

2. CBF

s.t. Ḣ(x) + αH(x) ≥ 0，其中 H(x) ≥ 0 定义安全集，α > 0。由比较引理，H(x(0)) ≥ 0 → H(x(t)) ≥ 0 ∀t（前向不变），即系统永不离开安全集。

3. RMA 三步

① 教师：在仿真里用特权信息（摩擦、质量、电机强度、地形）训练策略； ② 学生：只用可观测的 (o, a) 历史，回归教师提供的环境因子 z（本质是一个隐式系统辨识器/观测器）； ③ 部署：π(a|o, ẑ)，ẑ 由历史在线更新。

与 MRAC 的对应：MRAC 用跟踪误差在线调参数（有模型结构假设）；RMA 用历史回归隐参数（无显式模型），但都是"在线估计 → 条件化控制"。

4. advantage 归一化

A ← (A - mean(A)) / std(A)。它是一个逐批次的仿射变换，对所有动作施加同一变换 → 不改变 argmax_a A（最优动作顺序不变），也不改变策略梯度的方向（只改变步长）。它改变的是数值尺度（防止梯度爆炸/消失），没改变的是最优策略。

五、论文速读（20 分）

1. 特权信息（6 分）：地面摩擦系数、地形高度/法向、机身质量与负载、电机强度/延迟、接触状态、外部扰动。部署时传感器测不到或噪声极大（无法直接测摩擦系数与负载），只能从响应反推。

2. 学生输入/输出（7 分）：输入是最近 k 步的 (o_t, a_t) 历史；输出是环境因子向量 z ∈ R^d（教师训练时用真值）。本质：它在学一个非线性观测器/系统辨识器——从可观测的输入输出序列反推不可测的系统参数。

3. z 有误差会怎样（7 分）：策略条件在错误的 z 上 → 行为退化为"用错参数的控制器"，可能过度保守（不敢走）或过度激进（打滑摔倒）。两条鲁棒手段： - 训练时给 z 加噪（把估计误差建模进训练分布，等价于"鲁棒化"）； - 让 z 只保留低维/慢变分量（限制估计器的敏感度），或对 z 做时间平滑（低通），避免抖动。
