## 一、指标定义（先看这个再看表）

| 列 | 定义 | 回答什么问题 |
|---|---|---|
| `iters` | 训练迭代数（1 轮 = `16 步 × 64 env` = 1024 步） | 训练量 |
| `len95` | 平均回合长度**首次持续 ≥ 284**（上限 299）的迭代 | 多久学会活下来 |
| `std.2` | `mean_noise_std` **首次持续 ≤ 0.2** 的迭代 | 多久动作变确定 |
| `std.1` | 同上，≤ 0.1 | 是否过度收敛 |
| `reward` | 末轮 `Train/mean_reward` | **不可跨配置比** |
| `util` | `reward / (299 × alive)` | 离奖励上限还差多少 |
| `jit100` | 末 100 轮 reward 的标准差 | "抖动"的量化 |
| `vf` | 末轮 `Loss/value_function` | critic 拟合难度（跟尺度走） |

## 四、单条记录模板（复制粘贴用）

```markdown
### E3-x · 一句话标题

- **日期**：
- **假设**（先写！）：
- **只改了**：`文件:行` 从 `旧值` → `新值`
- **没改**：（列出你确认没动的：init / 终止条件 / alive / action_scale / 网络 / PPO 超参）
- **命令**：`python scripts/rsl_rl/train.py --task=Template-Cartpole-Direct-v0 --num_envs=64 --max_iterations=500 --seed=0`
- **run 目录**：`logs/rsl_rl/cartpole_direct/<时间戳>`
- **指标**（compare_runs 生成）：
- **评估**（eval 网格）：成功率 __%，残差角 __°，力矩 RMS __ N
- **结论（带强度）**：观察到 / 证据支持 / 否证
- **意外发现**：
```

## 五、结论强度约定

| 强度 | 条件 | 允许的措辞 |
|---|---|---|
| 观察 | 1 个 run | "我观察到……" |
| 可能 | ≥3 种子，方向一致 | "有迹象表明……" |
| 证据支持 | ≥3 种子 + eval 网格一致 + 只有 1 个变量 | "在 X 条件下，A 比 B 更好" |
| 否证 | 预期与实测方向相反 | "我原来的假说错了，新假说是……" |

⚠ 「否证」是四种里最值钱的，别怕写。
