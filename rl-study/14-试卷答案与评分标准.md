# A 卷答案

## 一、填空（每空 2 分）

1. 贝尔曼最优算子（`max` 算子）；**γ-压缩**（`||TV - TU||∞ ≤ γ||V - U||∞`）；**Banach 不动点**。
2. **一步 TD**（`δ_t = r + γV(s') - V(s)`）；**蒙特卡洛**（`G_t - V(s_t)`）。
3. **概率比** `r_t(θ) = π_θ/π_old`；`1-ε`；`1+ε`。
4. **函数逼近**、**自举（bootstrapping）**、**off-policy 数据**。
5. `γΦ(s') - Φ(s)`（势函数之差）。

**给分点**：每空 2 分，术语对但表述模糊给 1 分。

## 二、判断并说明理由（每题 3 分：判断 1 分 + 理由 2 分）

**1. 错。** 减基线的原理不是"数值变小"，而是 `E_{a~π}[∇_θ log π_θ(a|s)] = ∇_θ Σ_a π_θ = ∇_θ 1 = 0`，所以任意只依赖状态的基线都不改变期望，但能降低方差。

**2. 错。** 高斯策略的微分熵 `H = 0.5 ln(2πeσ²)`，`σ < 0.242` 后必然为负（微分熵可以为负）。判断探索强弱要看 `mean_noise_std` 本身。

**3. 错（不一定）。** `ε` 小 → 每步允许的更新更小 → 更稳，但**样本效率下降**，可能长时间卡在局部最优；`ε` 太小还会让 clip 频繁触发、梯度大量为 0。稳定性与效率是权衡，不是单调关系。

**4. 错。** `K = R⁻¹BᵀP`，`P` 只由 `(A,B,Q,R)` 决定，与 `x_0` 无关。LQR 是**状态反馈**，`x_0` 只影响轨迹，不影响增益。

**5. 错。** 观测器极点过快会放大测量噪声（`L` 大 → 噪声直接进估计），且可能激励未建模高频动态；实际要权衡"收敛速度 vs 噪声敏感度"，还要考虑采样频率（离散化后过快极点会失稳）。

## 三、推导（每题 8 分）

### 1. 策略梯度定理（给分点 2+2+2+2）

`p_θ(τ) = ρ_0(s_0) Π_t π_θ(a_t|s_t) P(s_{t+1}|s_t,a_t)` —— **2 分**

`∇_θ J = ∫ ∇_θ p_θ R dτ = ∫ p_θ ∇_θ log p_θ · R dτ = E[∇_θ log p_θ · R]` —— **2 分**
（log-derivative trick：`∇p = p∇log p`）

取对数后 `log p_θ = log ρ_0 + Σ_t log π_θ + Σ_t log P`，其中 `ρ_0` 与 `P` **不含 θ**，梯度为 0，故 `∇_θ log p_θ = Σ_t ∇_θ log π_θ(a_t|s_t)` —— **2 分**

因果性：`a_t` 不影响 `t` 之前的奖励，所以 `E[∇log π(a_t|s_t)·r_{t'}] = 0 (t' < t)`，可把 `R(τ)` 换成 `G_t = Σ_{t'≥t} γ^{t'-t} r_{t'}` —— **2 分**

减基线：`E_{a}[∇log π(a|s)b(s)] = b(s)Σ_a ∇π(a|s) = b(s)∇1 = 0`，故可用 `G_t - b(s_t)`，期望不变、方差下降。

> **总式**：`∇_θ J = E[Σ_t ∇_θ log π_θ(a_t|s_t)(G_t - b(s_t))]`

### 2. GAE λ=1 = MC（给分点 4+4）

$A_t^{\mathrm{GAE}} = \sum_{l\ge0}(\gamma\lambda)^l\,\delta_{t+l}$，其中 $\delta_t = r_t + \gamma V(s_{t+1}) - V(s_t)$ —— 4 分

$\lambda=1$ 时展开：

$$
\sum_{l\ge0}\gamma^l\left[r_{t+l} + \gamma V(s_{t+l+1}) - V(s_{t+l})\right]
= \sum_{l\ge0}\gamma^l r_{t+l} + \sum_{l\ge0}\gamma^{l+1}V(s_{t+l+1}) - \sum_{l\ge0}\gamma^l V(s_{t+l})
$$

后两项逐项相消（望远镜求和），只剩 $-V(s_t)$（终止时 $V(s_T)=0$）：

$$
= G_t - V(s_t) \qquad\text{—— 4 分}
$$

### 3. 标量 LQR 的 Riccati（给分点 3+2+3）

HJB：$0 = \min_u\left[qx^2 + ru^2 + V_x(ax+bu)\right]$，猜 $V = px^2$，$V_x = 2px$ —— 3 分

对 $u$ 求导：$2ru + 2pxb = 0 \Rightarrow u^* = -\dfrac{pb}{r}x$ —— 2 分

代回：

$$
qx^2 + \frac{p^2b^2}{r}x^2 + 2apx^2 - 2\frac{p^2b^2}{r}x^2 = 0
\;\Longrightarrow\;
2ap - \frac{b^2}{r}p^2 + q = 0 \qquad\text{—— 3 分}
$$

即 $u = -Kx$，$K = \dfrac{pb}{r}$。与矩阵形式 $A^\top P + PA - PBR^{-1}B^\top P + Q = 0$ 一致。

### 4. PPO clip 的梯度（给分点 4+4）

`r > 1+ε` 时 `clip(r,1-ε,1+ε) = 1+ε`，`A>0` 时 `(1+ε)A` 是常数，`min(rA, (1+ε)A) = (1+ε)A`（因为 `rA > (1+ε)A`） —— 4 分

所以 `L^CLIP` 在该区间是**常数**，`∂L/∂r = 0`。这限制的是"**让好动作概率继续增大**"这一侧（reward-increasing side），防止一次更新把某个动作概率推得过高。

## 四、计算（每题 6 分：式子 3 分 + 结果 3 分）

### 1. 两状态 MDP

`V(A) = max{1 + 0.9V(A), 2 + 0.9V(B)}`，`V(B)` 对称。

- 若 `stay` 最优：`V = 1/(1-0.9) = 10`；
- 若 `switch` 最优：`V = 2 + 0.9V → V = 20`。

比较：`switch` 给 20 > `stay` 给 10 → **`V*(A)=V*(B)=20`，最优策略是永远 switch**。
检验：`2 + 0.9×20 = 20` ✅，且 `1 + 0.9×20 = 19 < 20` ✅。

### 2. 三步 GAE

`δ_0 = 1 + 0.9×4 - 5 = -0.4`
`δ_1 = 0 + 0.9×3 - 4 = -1.3`
`δ_2 = 2 + 0 - 3 = -1`

- `λ=0`：`A_0 = -0.4`
- `λ=1`：`A_0 = -0.4 + 0.9(-1.3) + 0.81(-1) = -2.38`（核对 MC：`G_0 = 1 + 0.81×2 = 2.62`，`2.62-5 = -2.38` ✅）
- `λ=0.95`：`γλ = 0.855`，`(γλ)² = 0.731025`
  `A_0 = -0.4 + 0.855(-1.3) + 0.731025(-1) = -2.2425`

### 3. 2R 雅可比

$$
J = \begin{bmatrix}
-l_1s_1 - l_2s_{12} & -l_2s_{12}\\
l_1c_1 + l_2c_{12} & l_2c_{12}
\end{bmatrix}
$$

$s_1 = 0.5,\ c_1 = 0.8660,\ s_{12} = \sin 90^\circ = 1,\ c_{12} = 0$，所以

$$
J = \begin{bmatrix} -1.5 & -1.0\\ 0.866 & 0\end{bmatrix},
\qquad \det(J) = (-1.5)(0) - (-1)(0.866) = 0.866
$$

核对：`l₁l₂ sin q₂ = 1×1×sin60° = 0.866` ✅（非奇异）

## 五、简答（每题 5 分）

### 1. alive 放大 5 倍为什么不会"快 5 倍"（给分点 3+2）

advantage 是**相对量**：`A(s,a) = Q(s,a) - V(s)`。`alive` 是每步常数，它在 `Q` 和 `V` 里同时出现，相减时**被抵消**（更严格地说，PPO 还做两次归一化 `(A-mean)/std`，常数项在减均值时直接消失）。

所以放大 `alive` 不改变"哪个动作更好"的排序，只改变数值尺度（进而影响 critic 目标、KL、lr 刹车）。**真正决定学得快慢的是"惩罚项/终止项提供的相对信号"**，不是常数奖励的绝对值。

→ 3 分：指出 advantage 相减抵消；2 分：指出归一化也消除尺度。

### 2. 内环 PD + 外环 RL（每条 1.7 分）

1. **稳定性**：PD 提供阻尼，抑制高频振荡；策略只需负责低频决策，误差不会直接变成大幅力矩。
2. **动作空间**：位置目标幅值有界、物理意义明确，探索更安全；力矩输出容易饱和/发散。
3. **sim2real**：PD 是"模型无关"的快速反馈，能吃掉一部分模型误差与延迟；学习策略的推理延迟不进入内环。

### 3. 分离原理（给分点 3+2）

**内容**：线性系统 `ẋ = Ax + Bu, y = Cx` 下，`u = -Kx̂`（`x̂` 由 Luenberger 观测器给出）的闭环极点 = `eig(A-BK) ∪ eig(A-LC)`。所以控制器和观测器可以**独立设计**。

**成立条件**：系统线性、观测器线性、无噪声/或噪声统计已知。

**非线性下不成立**：估计误差 `e = x - x̂` 会进入非线性控制律，与状态耦合（不是简单的极点叠加），可能激励未建模动态而失稳。

# B 卷答案

## 一、系统设计（20 分：观测 4 + 奖励 8 + 终止 3 + 评估 3 + 冲突 2）

**观测（4 分）**：`o = [θ (rad), ω (rad/s), x (m), v (m/s), (x* - x) (m)]`，5 维。用差值而不是 `x*` 绝对值：数学等价，但省掉网络一次减法，收敛更快。

**奖励（8 分）**：每项都要有公式 + 量纲 + 典型量级。

$$
\begin{aligned}
r_{\text{alive}}  &= 1.0\,(1-\text{terminated}), & \text{无量纲} &\sim 1\\
r_{\text{pole}}   &= -1.0\,\theta^2, & \mathrm{rad}^2 &\sim 0.001\text{-}0.05\\
r_{\text{target}} &= -1.0\,\min\left(1, (x-x^*)^2\right), & \mathrm{m}^2 &\sim 0\text{-}1\\
r_{\text{cart\_}v} &= -0.01\,|v|, & \mathrm{m/s} &\sim 0.001\text{-}0.01\\
r_{\text{pole\_}v} &= -0.005\,|\omega|, & \mathrm{rad/s} &\sim 0.001\text{-}0.01
\end{aligned}
$$

**为什么**：`r_target` 用 `min(1, ·)` 裁剪，避免远离目标时惩罚过大（否则策略会"不敢动"）；量级统一到 O(1)，便于跨配置比较。

**终止（3 分）**：`|θ| > π/2`、`|x| > 3` → **terminated**（真正失败，要给 `-10`）；时间到 5 s → **truncated**（超时，不算失败，要 bootstrap `V(s_T)`）。二者混为一谈会导致"越接近上限价值越被低估"。

**评估（3 分）**：`x* ∈ {-2,-1,0,1,2}` × `θ0 ∈ {-0.3π,-0.2π,0,0.2π,0.3π}`，每格 32 env，动作取**均值**（确定性），指标：到位率（`|x-x*|<0.1` 且未终止）、平均残差角、力矩 RMS。

**冲突（2 分）**：`r_target` 和 `r_pole` 打架——为了到目标必须移动，移动会让杆子倒。**用势函数解决**：`F = γΦ(s') - Φ(s)`，`Φ = -0.5k(x-x*)²`，理论上不改变"保持竖直"的最优策略，只加速"靠近目标"的学习。

## 二、编程（20 分：代码 10 + 说明 6 + 自测 4）

```python
import numpy as np

def compute_gae(rewards, values, dones, gamma=0.99, lam=0.95, last_value=0.0):
    T = len(rewards)
    adv = np.zeros(T, dtype=np.float64)
    ret = np.zeros(T, dtype=np.float64)
    next_value = float(last_value)
    gae = 0.0
    for t in reversed(range(T)):
        not_done = 1.0 - float(dones[t])
        delta = rewards[t] + gamma * not_done * next_value - values[t]
        gae = delta + gamma * lam * not_done * gae
        adv[t] = gae
        ret[t] = gae + values[t]
        next_value = values[t]
    return adv, ret
```

**为什么从后往前**（6 分）：GAE 的定义是"未来 TD 残差的折扣和"，是**后向递推** `A_t = δ_t + γλA_{t+1}`；正向无法写（需要未来信息）。同时 `next_value` 要从最后一步往前更新。

**终止 vs 超时**：`dones=1` 时 `not_done=0` → `delta = r - V`、`gae = delta`，不 bootstrap。**但严格说，超时（truncated）应该 bootstrap**：此时 episode 只是被截断，真实价值不为 0。若 `dones` 里混了超时，需要单独传 `truncated` 并令 `last_value = V(s_T)`。这是最常见的实现 bug。

**自测**（4 分）：用 A 卷四.2 的数据 `r=[1,0,2], V=[5,4,3], dones=[0,0,1], γ=0.9, λ=0.95`，应得 `adv[0] = -2.2425`，`ret[0] = 2.7575`。

## 三、曲线诊断（每题 6-7 分：原因 4 + 验证 2-3）

### A：训练指标很好，eval 只有 40%

**最可能原因**：训练指标是"训练分布上的随机策略滑动平均"，而 eval 是"确定性动作 + 指定初始角"。训练时策略带噪声（`std` 到 330 轮才降到 0.2），噪声掩盖了"边缘初始角下的失败"；一旦去掉噪声，边缘条件就暴露。

**验证**：① 用同一组初始角做 eval，对比"确定性 vs 随机采样"成功率；② 扫初始角网格（0 → ±0.3π）看成功率曲线；③ 检查训练初始分布是否真的覆盖 ±0.3π。

### B：回合长度卡在 132

**最可能原因**：`initial_pole_angle_range = [-1.0, 1.0]`，单位是 **π 的倍数** → ±180°，而终止条件是 `|θ| > π/2`。约一半环境**第一步就终止**，理论上限 `0.5×299 + 0.5×1 ≈ 150`，实测 132 就在这个天花板下。

**验证**：把 range 改到 `[-0.49, 0.49]` 重训；若 `len95` 立刻出现，证明是终止条件而非策略能力。

### C：std 从不下降

**最可能原因**：奖励没有区分度（`util=1.0`，说明"活下来"就满分），advantage 几乎为常数 → 策略项梯度 ≈ 0，只有熵项在缓慢压低 std 且被归一化后微弱；也可能 `entropy_coef` 太小。

**验证**：① 把初始分布加难（±0.4π）或加动作惩罚，让"做得好"有区分度，观察 std 是否下降；② 把 `entropy_coef` 从 0.005 提到 0.05 看 std 下降是否变快（若变快，说明是熵项主导）。

## 四、原理（每题 5 分）

**1. MPC vs RL 的判据**

选 MPC：模型可得且较准、有硬约束（力矩/位置/安全）、需要可解释/可验证、实时性可通过 QP 满足。
选 RL：模型难建（接触、摩擦、变形）、需要从数据学复杂行为、任务用奖励描述比用模型描述容易、可接受仿真训练成本。
**判据不是"哪个先进"，而是"模型误差 vs 数据量"**：模型准 → MPC；数据多且模型不准 → RL；两者都有 → 残差学习/学习型 MPC。

**2. CBF**

`s.t. Ḣ(x) + αH(x) ≥ 0`，其中 `H(x) ≥ 0` 定义安全集，`α > 0`。由比较引理，`H(x(0)) ≥ 0 → H(x(t)) ≥ 0 ∀t`（前向不变），即系统永不离开安全集。

**3. RMA 三步**

① 教师：在仿真里用特权信息（摩擦、质量、电机强度、地形）训练策略；
② 学生：只用可观测的 `(o, a)` 历史，回归教师提供的环境因子 `z`（本质是一个**隐式系统辨识器/观测器**）；
③ 部署：`π(a|o, ẑ)`，`ẑ` 由历史在线更新。

与 MRAC 的对应：MRAC 用跟踪误差在线调参数（有模型结构假设）；RMA 用历史回归隐参数（无显式模型），但都是"**在线估计 → 条件化控制**"。

**4. advantage 归一化**

`A ← (A - mean(A)) / std(A)`。它是一个**逐批次的仿射变换**，对所有动作施加同一变换 → 不改变 `argmax_a A`（最优动作顺序不变），也不改变策略梯度的方向（只改变步长）。它改变的是**数值尺度**（防止梯度爆炸/消失），没改变的是**最优策略**。

## 五、论文速读（20 分）

**1. 特权信息（6 分）**：地面摩擦系数、地形高度/法向、机身质量与负载、电机强度/延迟、接触状态、外部扰动。部署时**传感器测不到或噪声极大**（无法直接测摩擦系数与负载），只能从响应反推。

**2. 学生输入/输出（7 分）**：输入是最近 `k` 步的 `(o_t, a_t)` 历史；输出是环境因子向量 `z ∈ R^d`（教师训练时用真值）。**本质**：它在学一个**非线性观测器/系统辨识器**——从可观测的输入输出序列反推不可测的系统参数。

**3. z 有误差会怎样（7 分）**：策略条件在错误的 `z` 上 → 行为退化为"用错参数的控制器"，可能过度保守（不敢走）或过度激进（打滑摔倒）。两条鲁棒手段：
- 训练时给 `z` 加噪（把估计误差建模进训练分布，等价于"鲁棒化"）；
- 让 `z` 只保留低维/慢变分量（限制估计器的敏感度），或对 `z` 做时间平滑（低通），避免抖动。

# 最常见的 8 个错误（改卷时重点看）

1. 把 PPO 的 clip 说成"裁剪动作"。
2. 以为熵为负 = 探索死掉。
3. GAE λ=1 时算不出 MC 的数值（终止处理写错）。
4. LQR 说成"增益依赖 x0"。
5. 把 terminated 和 truncated 混为一谈（B 卷二必查）。
6. GAE 代码里对超时也 `not_done=0`（少 bootstrapping）。
7. 奖励设计不写量纲（B 卷一直接扣分）。
8. 诊断题只给"可能是 A/B/C"，不给"怎么验证"。
