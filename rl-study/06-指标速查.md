# 指标速查

> 看不懂某条曲线时翻这里。每条指标：**是什么 → 你的正常范围 → 异常怎么办**。
> 数据全部来自你自己的 9 个 run（见 [04-实验台账](08-实验台账.md)）。

## 一、六条主指标

| 指标 | 是什么 | 你的正常范围 | 异常时先查 |
|---|---|---|---|
| `Train/mean_reward` | 最近完成回合的平均回报 | 取决于 `alive`：1→约 297，2→约 594，5→约 1492 | 先算 `util = reward/(299×alive)`，别跨配置比绝对值 |
| `Train/mean_episode_length` | 平均回合长度（上限 299） | 收尾 299 | 卡在 130-150 → 初始状态有一半"第一步就死"（终止条件问题，不是策略问题） |
| `Policy/mean_noise_std` | 动作分布的标准差 | 起步 1.0，收尾 0.02-0.05 | 一直 1.0 → 奖励没区分度；掉太快 → 卡在次优 |
| `Loss/value_function` | critic 的 MSE | 0.001-0.04（跟奖励尺度走） | 大于 1 → 目标值太大或奖励尺度太野 |
| `Loss/surrogate` | 策略损失，带着 $-\hat A$ | 约 $-0.01$ ~ $+0.01$ | **越小不代表越好**，看有没有剧烈震荡 |
| `Loss/learning_rate` | KL 刹车后的学习率 | 在 $10^{-5}$ 与 $10^{-2}$ 之间跳 | 不要读成"衰减"，它反映"这批数据多出人意料" |

## 二、三个容易误读的地方

**1. `Loss/entropy` 是负的很正常。**
高斯策略的微分熵（$\sigma$ 是标准差）：

$$
H = \tfrac12\ln\left(2\pi e\,\sigma^2\right)
$$

$\sigma < 0.242$ 之后必然为负。你日志里 $\sigma\approx0.035$ 时 $H\approx-1.92$，和 TensorBoard 的 $-1.939$ 对得上。**判断探索强弱看 `std`，别看熵的正负。**

**2. `Loss/learning_rate` 不是衰减曲线。**
`desired_kl = 0.01`，实测 KL 超过 $2\times$ 目标就除以 1.5，低于一半就乘 1.5。所以它在地板 $10^{-5}$ 和天花板 $10^{-2}$ 之间来回弹。

**3. `Episode/Reward/*` 分项默认没有。**
你这个 Direct 环境只回传标量奖励。要看得自己往 `self.extras["log"]` 里写（[01-教程](01-教程-总览.md) 第 4 步有改法）。

## 三、三个诊断流程

**A. reward 不涨**

1. `util` 有没有到 0.99？到了就别看 reward 了，去看 eval。
2. 回合长度涨不涨？不涨 → 查终止条件（初始分布是否越界）。
3. `std` 有没有动？不动 → 查奖励有没有区分度。

**B. `std` 不降**

1. `util` 是不是已经 1.0（"活下来"就满分）→ 任务太容易，加难度。
2. `entropy_coef` 是不是偏大？0.005 时熵项约 0.007，和 surrogate 同量级。
3. 是不是 policy 项梯度被 clip 吃掉了 → 看 `surrogate` 是否长期贴 0。

**C. 训练指标好、eval 差**

1. eval 用的是确定性动作吗（关噪声）？
2. eval 的初始条件是否超出训练分布？
3. 是不是拿了 `model_499`（末期过拟合到"只站着"）而不是 eval 最好的 checkpoint？

## 四、命令

```bash
# 所有 run 压成一张表
python scripts/compare_runs.py --md

# TensorBoard
tensorboard --logdir logs/rsl_rl --port 6006

python scripts/policy_probe.py --policy logs/rsl_rl/cartpole_direct/<run>/exported/policy.pt

from tensorboard.backend.event_processing.event_accumulator import EventAccumulator
ea = EventAccumulator("logs/rsl_rl/cartpole_direct/<run>"); ea.Reload()
print(ea.Tags()["scalars"])
EOF
```
